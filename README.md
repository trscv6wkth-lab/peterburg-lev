# Петербург — город, который помнит

Учебный одностраничный сайт о Санкт-Петербурге. Автор: Муратов Лев, II А курс.

## Файлы

- `index.html` — содержание сайта, разделы, форма и лента отзывов.
- `styles.css` — адаптивное оформление и CSS-иллюстрации.
- `script.js` — мобильное меню и мини-викторина.
- `reviews.js` — рейтинг, отправка отзывов и загрузка опубликованных записей.
- `google-apps-script/Code.gs` — серверная часть формы. Новые записи сохраняются в автоматически созданную Google Таблицу «Петербург — отзывы»; на сайте отображаются последние 100 отзывов.
- `Отчет_Петербург_Муратов_Лев.docx` — учебный отчёт.

## Публикация

Сайт публикуется через GitHub Pages из корня ветки `main`. Apps Script развёрнут как веб-приложение, выполняется от имени владельца и принимает отзывы от всех посетителей сайта.

Адрес веб-приложения формы: `https://script.google.com/macros/s/AKfycbzuDErnO4PXZLddhLqIZouLArMLleyBie7RtjLUzKQt4JYpwSWqoMFLfh9dSiv_nzDr/exec`.

Отзывы публичны: форма предупреждает посетителей не оставлять телефоны, адреса и другие личные данные. Скрипт хранит имя или псевдоним, оценку, текст отзыва и дату отправки.

## Локальный просмотр

Откройте `index.html` в браузере. Без сетевого доступа шрифты заменяются системными, а отзывная лента не загрузится из Apps Script.
